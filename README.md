# EFE Illustration · Proyecto web de DAM

Sitio web estático desarrollado como proyecto académico de **Lenguajes de Marcas** durante el ciclo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

El proyecto presenta una web de ilustración con varias páginas enlazadas y una galería de tarjetas con animación. Se publica como muestra de aprendizaje de HTML y CSS, no como una aplicación comercial en producción.

## Tecnologías

- **HTML5:** estructura de páginas, navegación y controles de formulario.
- **CSS3:** estilos compartidos, Flexbox, Grid, transiciones y transformaciones 3D.
- **Boxicons:** iconos de la página de servicios mediante una hoja de estilos externa.

No requiere un proceso de compilación y no incluye JavaScript, backend ni base de datos.

## Contenido

| Archivo | Función |

## Ejecutar en local

Descargar o clonar el repositorio y abrir `index.html` en un navegador. Es importante conservar la estructura de carpetas y los nombres de los archivos.

Los iconos de Boxicons se cargan desde un servicio externo y requieren conexión a Internet.

## Alcance y limitaciones

Esta versión conserva el alcance del ejercicio académico. Incluye textos de ejemplo y enlaces de muestra sin destino definitivo.

El formulario original utiliza `mailto:` con una dirección de ejemplo. **No está conectado a un servicio de recepción de mensajes ni guarda información en una base de datos.** No debe utilizarse para enviar datos personales reales.

Como mejoras futuras se contemplan sustituir los textos de muestra, optimizar el peso de las imágenes y revisar la adaptación a pantallas pequeñas y la accesibilidad.

## Preparación para publicar

Se han normalizado las referencias a la carpeta `assets/`, corrigiendo las rutas que utilizaban `Assets/`. Se conserva el diseño y el contenido del proyecto original.
